# Homebrew Apps (archived)

This tap is no longer maintained. Both projects now ship official Homebrew casks:

```sh
brew install --cask SakuraCordApp/tap/sakuracord
brew install --cask robbietilton-compositor
```

If you installed from this tap, switch over:

```sh
brew uninstall --cask lostf1sh/apps/sakuracord lostf1sh/apps/compositor
brew untap lostf1sh/apps
```
